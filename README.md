# 🚀 Advanced Programming (Java & C++)

¡Bienvenido a mi repositorio de **Advanced Programming**! Este espacio está dedicado a almacenar, organizar y documentar mis proyectos, laboratorios y talleres de programación utilizando lenguajes de alto rendimiento como **Java** y **C++**.

El objetivo de este repositorio es realizar un seguimiento de mi progreso académico y técnico en el desarrollo de software estructurado, orientado a objetos y resolución de algoritmos.

---

## 📂 Estructura del Repositorio

El proyecto se encuentra organizado de la siguiente manera para mantener el código limpio y accesible:

*   **`📁 Java/`** — Todo el desarrollo basado en la plataforma Java.
    *   `📁 proyects/` — Aplicaciones completas y proyectos principales del curso.
    *   `📁 workshops/` — Ejercicios prácticos, retos semanales y talleres de lógica.
      
*   **`📁 C++/`** — Todo el desarrollo basado en la plataforma C++.
    *   `📁 proyects/` — Aplicaciones completas y proyectos principales del curso.
    *   `📁 workshops/` — Ejercicios prácticos, retos semanales y talleres de lógica.

## 🚀 Cómo Ejecutar los Proyectos Localmente

Si quieres clonar este repositorio y probar el código en tu computadora, sigue estos pasos desde tu terminal:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/felipegb07/Advanced-Programming.git
   ```

2. **Navegar a la carpeta del proyecto:**
   ```bash
   cd Advanced-Programming
   ```

3. **Abrir con tu IDE preferido:**
   * Abre la carpeta raíz en **IntelliJ IDEA**, **VS Code** o **Code::Blocks**para ejecutar los archivos `.java` o `.cpp`.
